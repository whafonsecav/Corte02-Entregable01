## Cómo se navega

- Flechas `←` `→` (también `↑` `↓`, `Espacio`, `Re Pág` / `Av Pág`)
- Clic con el mouse: mitad derecha avanza, mitad izquierda retrocede
- Rueda del mouse, deslizar en pantallas táctiles, o los puntos del pie de página
- `Inicio` / `Fin` para ir a la primera o última lámina · `F` para pantalla completa
